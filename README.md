# Cold Email LLM Agent

A multi-stage cold email generation agent built with Python, LangChain, and a locally hosted Ollama LLM.

The system analyzes a candidate profile against a job description, identifies relevant candidate-job alignment, generates a personalized cold email, and reviews the generated draft to reduce unsupported claims and LLM hallucinations.

## Features

* Local LLM inference using Ollama
* Multi-stage LangChain prompt pipeline
* Candidate and job context analysis
* Dynamic context injection between LLM chains
* Personalized cold email generation
* LLM-based grounding and quality review
* Hallucination reduction using prompt constraints
* Deterministic output cleaning
* Dynamic command-line input

## How It Works

The application uses three LLM chains that perform separate stages of the cold email generation process.

### 1. Context Analysis Chain

The first chain analyzes the candidate profile and job description.

It identifies:

* Relevant candidate skills
* Primary job requirements
* Candidate-job alignment
* The strongest outreach angle

The generated analysis is passed as context to the email generation chain.

### 2. Email Generation Chain

The second chain receives:

* Candidate profile
* Job description
* Company name
* Candidate name
* Context analysis generated by Chain 1

The extracted context is dynamically injected into the generation prompt.

The chain then creates a personalized cold email while following grounding constraints designed to prevent unsupported claims.

### 3. Grounding Review Chain

The third chain reviews the generated email against the original candidate profile and job description.

The reviewer checks for:

* Unsupported candidate claims
* Invented technologies or skills
* Incorrect job titles
* Invented achievements
* Invented attachments
* Generic corporate language
* Grammar and spacing issues

The reviewed email is then passed through deterministic output cleaning before being displayed.

## Prerequisites

Before running the project, install:

* Python 3
* Ollama

The application uses the Llama 3.2 model through Ollama.

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd cold-email-llm-agent
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment on Windows:

```bash
venv\Scripts\activate
```

Install the required Python packages:

```bash
pip install -r requirements.txt
```

Pull the Llama 3.2 model using Ollama:

```bash
ollama pull llama3.2
```

## Usage

Run the application:

```bash
python main.py
```

The application asks for:

1. Candidate name
2. Company name
3. Candidate profile
4. Job description

When entering the candidate profile, type `END` on a new line after finishing.

When entering the job description, type `END` on a new line after finishing.

Example:

```text
=== COLD EMAIL LLM AGENT ===

Candidate Name: Abhinav Kumar Singh
Company Name: OpenAI

Paste Candidate Profile.
Type END on a new line when finished:

Python developer with experience in machine learning,
React, Next.js, Flask, SQL, and building AI applications.
Built an injury classification system using deep learning.
END

Paste Job Description.
Type END on a new line when finished:

We are hiring a Software Engineering Intern.
The candidate should have experience with Python
and building software applications.
END
```

The agent processes the input through the three-stage LLM pipeline and returns a reviewed cold email.

## Hallucination Reduction

Initial email generations occasionally introduced unsupported claims, such as candidate skills or experience that appeared only in the job description.

To reduce this behavior, the application uses a separate grounding review chain.

The reviewer compares the generated email against the original candidate profile and job description and removes claims that cannot be supported by the provided candidate context.

This creates a multi-stage generation and validation pipeline rather than relying on a single LLM prompt.
